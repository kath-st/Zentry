ESTRUCTURAS DE DATOS UTILIZADAS

PRINCIPAL: LinkedList[EventCatalog]
├─ Nodos genéricos con tipo T
├─ Inserción al final O(n)
├─ Eliminación O(n)
├─ Búsqueda O(n)
├─ Filtrado O(n)
├─ MergeSort O(n log n) estable
├─ QuickSort O(n log n) promedio
└─ BinarySearch O(log n) en datos ordenados

COMPLEMENTARIA: dict[int, EventCatalog]
├─ Índice rápido por ID
├─ Acceso O(1)
└─ Mantiene sincronización con LinkedList

EJEMPLO RÁPIDO DE USO
========================================================================

from core.services.event_catalog_service import EventCatalogService
from core.domain.event_catalog import EventCatalog
from datetime import datetime, timedelta

# Crear servicio
service = EventCatalogService()

# Crear evento
event = EventCatalog(
    id=1,
    name="Rock Night",
    venue="Estadio",
    date=datetime.now() + timedelta(days=7),
    min_price=50.0,
    max_price=150.0,
    total_capacity=5000,
    sold_tickets=2500,
    artist_name="The Beatles"
)

# Añadir al catálogo
service.add_event(event)

# Buscar
results = service.search_by_name("rock")

# Ordenar por fecha
sorted_events = service.sort_by_date(algorithm="merge")

# Eventos trending
trending = service.get_trending_events(limit=10)
